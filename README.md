# Roastify Telegram Bot 🤖🔥

তুমি লেখো, বাকি অপমান আমরা করবো 😈

## Features ✨

### Core Features
- **No-command operation** - Just send text, get roasted
- **3D Styled Image Generation** - Beautiful visual roasts
- **Smart Text Analysis** - Context-aware roasting
- **Multiple Response Types** - Image + Text + Diagram
- **Bangla Language Support** - Full Unicode support

### Social Features
- **Auto Reactions** - Smart emoji reactions
- **Voting System** - Rate roasts with inline buttons
- **User Leaderboard** - Track most roasted users
- **Mention Roasting** - Roast specific users in groups
- **Welcome System** - Multiple welcome messages

### Visual Features
- **Random Borders** - 10+ stylish border styles
- **Multiple Fonts** - Random font selection
- **Time-based Themes** - Day/Night mode
- **Template System** - 50+ roast templates
- **3D Text Effects** - Depth, shadows, glow

### Advanced Features
- **Admin Protection** - Safe from abuse
- **Auto-feature Loading** - Add features dynamically
- **24/7 Uptime** - Always online
- **Database Backup** - Automatic backups
- **Festival Modes** - Special themes for events
